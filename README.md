The whole site is one file, `index.html`. Course files stay in Google Drive and are linked from the page.

## Publish on GitHub Pages
1. Create a new public repository (`PHDENG2214`).
2. Upload `index.html` and this `README.md` to the main branch.
3. Settings → Pages → Source: "Deploy from a branch" → `main` / root → Save.
4. The site appears at `https://carlovillalona.github.io/PHDENG2214/` after a minute or two.
